About TS Library

Library Management System

TS Library is a Library Management System designed to help librarians efficiently manage books, members, book issuing, and return operations. The system provides a centralized platform for maintaining library records and monitoring book availability.

Key Features

  • Book Management
  • Member Management
  • Issue Book Tracking
  • Return Book Tracking
  • Dashboard Statistics
  • Availability Monitoring

Development Team

Developed as an academic project to demonstrate the implementation of a modern Library Management System using Spring Boot, Thymeleaf, MySQL, HTML, CSS, and Java.
